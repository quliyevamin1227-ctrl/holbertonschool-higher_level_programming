# JavaScript - DOM manipulation

Scripts that select, style, update and create HTML elements in the browser, listen to user events, and load data with the Fetch API.

| File | Description |
| --- | --- |
| `0-script.js` | Sets the `header` text color to red (`#FF0000`) with `document.querySelector` |
| `1-script.js` | Turns the `header` red when `#red_header` is clicked |
| `2-script.js` | Adds the class `red` to the `header` when `#red_header` is clicked |
| `3-script.js` | Toggles the `header` class between `red` and `green` when `#toggle_header` is clicked |
| `4-script.js` | Adds `<li>Item</li>` to `ul.my_list` when `#add_item` is clicked |
| `5-script.js` | Changes the `header` text to `New Header!!!` when `#update_header` is clicked |
| `6-script.js` | Fetches a Star Wars character and shows its name in `#character` |
| `7-script.js` | Fetches all Star Wars movies and lists their titles in `#list_movies` |
| `8-script.js` | Fetches "hello" in French and shows it in `#hello` (works when loaded from `<head>`) |
